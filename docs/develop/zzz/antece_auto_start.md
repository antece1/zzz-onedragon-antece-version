# 每天定时运行一条龙（antece版）

在一条龙界面设一个本地时间，每天到点自动运行一条龙。时间和开关存在 Windows「任务计划程序」里，界面关着也会运行。

## 用法

一条龙 → 一条龙运行 → 右边「运行设置」最后一张卡片「每天定时运行一条龙」：

- 时间：点开选好后点确认，马上保存。时间没变也可以再确认一次，用来重新保存（见下面「时区偏移」）。
- 开关：拨动后马上保存。
- 卡片下面一行是从 Windows 读到的状态，例如「已开启，下次运行 11-24 23:05」；鼠标停在卡片上能看到管理的是哪个计划任务、运行账户等。
- 保存失败时会弹出提示，卡片恢复成 Windows 里的实际状态。
- 开关关着时改时间：只保存时间，提示「定时运行未开启，打开开关后生效」。
- 保存在后台线程里做（第一次新建任务前要查遍所有计划任务，可能要 1 秒左右），保存期间卡片显示「正在保存…」，时间和开关不能操作。
- 卡片太窄时标题和状态文字末尾省略，鼠标停在文字上看完整内容。

## 管理哪个计划任务

代码：`src/zzz_od/utils/auto_start_utils.py`（规则）、`src/one_dragon/utils/task_scheduler_utils.py`（通过 COM 读写计划任务）。

运行一条龙的任务，按顺序找第一个存在的：

1. `config/auto_start.yml` 里的 `run_task_name`（填了就只管它，不存在时报错，也不会新建）
2. `KNOWN_RUN_TASK_NAMES`：以前手动建的一条龙任务（例如 `ZZZ OneDragon Daily 2330`）。只改时间和开关，不改名、不改运行内容
3. `APP_TASK_NAME`：本版自己建的任务 `ZZZ OneDragon antece Auto Start`

都没有时，打开开关会新建 `APP_TASK_NAME`。新建前会：

- 检查是不是管理员（任务要用最高权限运行，游戏是管理员进程）
- 检查当前进程的账户和登录桌面的账户是否相同（UAC 用了别的管理员账户时，新建的任务永远不会运行）
- 检查 `.venv\Scripts\python.exe`、`deploy\antece_daily_run.py`、`conhost.exe` 都存在
- 查重：已有任务的「启动程序」里出现仓库目录、`zzz_application_launcher`、`OneDragon-Launcher.exe`、`ZZZ-Auto.ps1` 或 `antece_daily_run.py` 时不新建，提示在 `run_task_name` 里写那个任务名（数据同步任务除外）。避免每天运行两次

米游社数据同步任务：

- `sync_task_name` 填了就用它；填 `-` 表示不管；不填时找 `KNOWN_SYNC_TASK_NAMES`（例如 `auto-zzz HoYoLAB sync 2300`），没有就不管
- 打开时把同步时间设为一条龙时间提前 5 分钟（跨午夜时绕回，例如 00:03 → 23:58）
- 只改时间，不动它的开关；关闭一条龙时不碰它；从不新建
- 保存时如果现在已经过了今天的同步时间、还没到一条龙时间，会提示今晚会用上次同步的数据（改了触发时间的任务不会补跑）

`config/auto_start.yml`（已加进 `.gitignore`，界面不会写它，需要时手动建）。改完后重新打开「一条龙运行」页面或再操作一次卡片就会生效，不用重启界面：

```yaml
run_task_name: '\我的任务\一条龙'   # 可带文件夹；留空 = 自动查找
sync_task_name: '-'                # 留空 = 自动查找；'-' = 不管同步任务
```

## 怎么改计划任务

- 用 COM（`Schedule.Service`），不用 schtasks.exe / PowerShell：不弹黑框、几毫秒一次、中文任务名不乱码、不会提示输入密码。
- 只改第一个「每天」触发器，其余设置（运行账户、权限级别、运行内容、说明等）原样重新注册。任务有多个每天触发器时只改第一个，鼠标提示里会写。
- 关闭开关 = 只关闭触发器，不关闭整个任务。整个任务关闭后，手动点「运行」也会失败（0x80041326）。
- 不支持：没有「每天」触发器的任务、设置了「不管用户是否登录都要运行」的任务（修改要密码）。读取时就在卡片上提示到任务计划程序里改。
- 任务可以在子文件夹里（例如 `\我的任务\一条龙`）：重新注册时用相对于所在文件夹的名称。
- 本版自己的任务：仓库搬家或换了 venv 时，保存时顺便把运行内容改成当前路径。用户自己的任务从不改运行内容。
- 修改用户以前建的任务一般要管理员权限（任务只给普通用户读权限）。界面不是管理员时提示用桌面快捷方式重新打开。
- 正在运行时保存不会打断这次运行。

### 时区偏移（夏令时）

写入的开始时间不带时区偏移（例如 `2026-11-24T23:05:00`），表示本地时间。
带偏移的（例如 `2026-11-22T23:05:00-08:00`，PowerShell `New-ScheduledTaskTrigger` 会这样写）是一个固定的 UTC 时刻，夏令时切换后会晚 / 早 1 小时运行。
读到带偏移的任务时，卡片按今天的时区换算显示实际运行时间，并提示重新保存一次；读取时不会自动改。

## 新建的任务长什么样

- 运行：`conhost.exe --headless <仓库>\.venv\Scripts\python.exe <仓库>\deploy\antece_daily_run.py --close-game`，起始目录为仓库
  - 用 `python.exe`，不用 `pythonw.exe`：Windows「智能应用控制」会拦截 venv 里没签名的 `pythonw.exe`
  - `conhost.exe --headless` 隐藏黑框
- 只在用户登录时运行，最高权限，运行账户为当前用户
- 用电池时也运行；已在运行时不启动新的；运行超过 12 小时停止（用户自己的任务是不限时）
- 错过时间不补跑（例如那时电脑关着），不唤醒电脑

## 定时运行入口 `deploy/antece_daily_run.py`

- 计划任务不能设置环境变量，由它切到仓库目录、把 `src` 加进搜索路径，再运行 `zzz_od.application.zzz_application_launcher`（和 OneDragon-Launcher 的一条龙模式是同一个入口）。不要改成调用 `OneDragon-Launcher.exe`：它会把代码重置成官方版本。
- 参数原样交给启动器：可以在任务的参数里手动改成 `-i 1,2`（只运行这两个账号）、`--shutdown` 等；不传参数时用 `--close-game`。注意它不看界面里「结束后」的选项。
- 参数解析通过后，先关掉正在运行的一条龙界面（按命令行里的 `src\zzz_od\gui\app.py` 判断，不按程序路径：入口自己的 python.exe 也在仓库目录下），再运行。两个进程同时写配置、同时操作游戏会出错。
- 日志：`.log/antece_daily_run.log`。`conhost.exe --headless` 不传子进程的退出码，任务计划程序里的「上次运行结果」总是 0，出错要看日志。
- 用户以前的任务（例如运行 `ZZZ-Auto.ps1` 的）不用这个入口，它自己的脚本负责这些。

## 注意

- 只在用户登录时运行；锁屏时游戏截图和点击可能不正常，最好不锁屏。睡眠 / 关机时不会运行。
- 夏令时开始那天不存在的时间（例如 02:30）会推迟运行。
- 无界面运行时用停止热键（设置里的「停止运行」按键）停止。
- 把时间设在 00:00 之后时，日期已经是第二天，按日期计算的东西（例如每天的体力计划）会算到第二天；也注意游戏每天刷新的时间。
